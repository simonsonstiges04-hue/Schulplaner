# Schulplaner

Persönlicher Schulplaner als installierbare Web-App: Hausübungen, Stundenplan, Prüfungen mit Lernfortschritt und der Familien-Google-Kalender in einer Ansicht.

- Läuft komplett im Browser, Daten liegen auf dem Gerät und als Sicherung im eigenen Google-Konto (Apps Script).
- In diesem Repo liegt nur der App-Code – keine Termine, keine Zugangsdaten.
